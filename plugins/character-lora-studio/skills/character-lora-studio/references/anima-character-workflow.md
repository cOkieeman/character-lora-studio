# Anima 角色 LoRA 详细流程

本流程用于 Anima 的 Booru-tag 角色 LoRA。它把数据生成、预处理、打标、正则和训练拆成独立门禁。教程示例、trainer UI 和参数会随版本变化；任何具体数值都要与当前 AnimaLoraStudio 和项目配置复核。

## 1. 锁定学习目标

先在 `角色配置.yaml` 写清：

- 唯一角色 trigger
- 是否需要独立 outfit trigger
- 必须一致的身份锚点
- 希望提示词可控制的发饰、服装、道具和身体特征
- 默认服装与换装策略
- 禁止漂移与禁止进入训练的形态

不要一边生成数据一边改变角色定义。新的设计解释必须先更新设计基准，再决定是否重做受影响图片。

## 2. 建立角色设计基准

从可信原图制作能看清正面、侧面、背面、下半身和关键配件的人设图。AI 补全只能作为候选，必须对照原始资料审查：

- 脸型、眼睛、发型和发色
- 前后发束、头饰和耳部结构
- 身体比例和皮肤身份特征
- 签名服装的前、侧、背结构
- 道具和配件是否固定、可控或应删除

模糊原图中的几何形状不要擅自命名为具体物件。错误解释一旦进入设计图，后续生成图会批量继承。

## 3. 设计生成矩阵

首版使用 15–60 张，通常先做 25–40 张高质量图。复杂可换装角色可扩展到 40–50 张。

先覆盖：

- 头部特写：正面 2、侧面 1、背面 1
- 上半身：正面 2、侧面 1、背面 1
- 全身：正面 2、侧面 1、背面 1
- 俯视和仰视
- 按阶段目标安排画风：白底身份包可少量固定，泛化包再扩展
- 不同表情、动作、背景和光影

提示词重点描述画风、构图、角度、动作和背景；通过设计参考锁定角色，而不是在每条生成提示里重新发明角色特征。

## 4. 小批生成和审查

按 4–8 张一批生成。每批建立带文件名的联系表，逐图检查：

- 身份锚点是否与设计基准一致
- 头颈躯干、肩脊骨盆和髋膝踝受力链
- 双手、手指、脚、服装遮挡和道具接触
- 画面是否提供新的镜头、动作、服装或画风价值
- 是否有文字、水印、签名、重复或过近构图

不合格图不得因“缺这个槽位”而保留。可局部修复的进入派生目录；会改变身份、骨骼或整张构图的直接替换。

## 5. 预处理

保留原图不变，并记录每张正式图的来源。派生处理可包括：

- 去除可见或不可见水印
- 局部重绘错误特征
- 裁切无价值边缘或修正桶比例
- 涂抹文字、残留物和小范围伪影

处理后重新做视觉检查。局部修复通过不代表原图的其他区域自动通过。分辨率优先接近 1024 训练桶，不为凑正方形而切掉头饰、手、脚或服装关键结构。

## 6. 导入与自动打标

导入前验证图片可解码、尺寸合理、哈希无重复。自动 tagger 完成后：

1. 保存原始 tag 快照。
2. 注入唯一角色 trigger。
3. 逐图删除错误、不可见、冲突、来源和质量 tag。
4. 按项目的概念绑定策略处理固定身份 tag。
5. 为签名服装使用独立 outfit trigger 时，只在对应图片注入。
6. 检查 token 顺序和 `keep_tokens`。
7. 输出修改统计和关键 tag 频次。

如果图片像素仍包含错误设计，仅删 caption 不足以修复训练污染。

## 7. 冻结正式训练集

正式集放入新的版本目录，并记录：

- 图片与 caption 对数
- 文件名、来源和 SHA-256
- 构图、视角、服装和画风分布
- 触发词和 outfit trigger 次数
- 已淘汰、待复核和替换项

冻结后任何图片或 caption 修改都创建新版本，不原地覆盖已做过 smoke 或完整训练的版本。

## 8. 建立正则

阅读 [regularization.md](regularization.md)。先做一次有边界的 AI prior 候选；如果身份距离、人体、画风或覆盖不合格，再使用 Gelbooru 等来源建立独立候选。正则不得包含角色 trigger、近似身份或完整签名组合。

## 9. 配置与 smoke

核对当前 trainer 版本、底模、VAE、文本编码器、GPU、VRAM、RAM 和磁盘。冻结 dataset、caption、regularization 和 config 后重建 cache，并运行 5–10 step smoke。

Smoke 必须确认：

- 模型和 caption 编码成功
- train/reg cache 对应当前版本
- 第一个 optimizer step 成功
- loss 有限且无 OOM、NaN、Traceback
- checkpoint 与样图可写出
- 结束后显存和系统资源释放

Smoke 通过不等于授权完整训练。

## 10. 完整训练与选丹

完整训练需要独立授权。按固定间隔保存 checkpoint 和样图，用固定 seed、prompt 和推理设置比较：

- 只写角色 trigger
- 角色身份上限
- 角色 + 签名服装 trigger
- 更换其他服装
- 特写、上半身、全身和背面
- 不同 LoRA 权重

选择最早达到身份稳定、同时换装和提示词响应仍良好的 checkpoint。不要只看最低 loss，也不要默认最后一轮最好。
