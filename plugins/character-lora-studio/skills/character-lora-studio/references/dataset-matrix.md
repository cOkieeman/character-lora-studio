# 数据集矩阵

## 基准规模

角色人形 v1 建议从 40–50 张高质量图开始。少于 25 张时，将服装压缩为 2–3 套；40 张以上可使用 5 套左右。质量和身份一致性优先于数量。

## 服装分配

推荐 5 套人形服装：

| 类型 | 建议占比 | 目的 |
|---|---:|---|
| 默认服装 | 30–40% | 稳定角色默认召回 |
| 都市便装 | 15–20% | 解除制服绑定 |
| 半正式／职业装 | 12–18% | 扩展成熟场景 |
| 主题换装 | 10–15% | 保留世界观或原设致意 |
| 居家／轻便装 | 10–15% | 增加材质与身体姿态变化 |

泳装、礼服和极端造型各控制在 2–4 张，优先留到扩展版。不要让单个非默认服装成为第二套隐性制服。

## 镜头分配

| 镜头 | 建议占比 |
|---|---:|
| 头部特写 | 15–20% |
| 上半身 | 30–35% |
| 膝上／大腿构图 | 15–20% |
| 全身 | 25–30% |
| 背面或结构视图 | 5–10% |

每套主要服装至少包含 2 张上半身和 1 张全身。默认服装需要更多正、侧、背结构信息。

## 视角与动作

- 正面和四分之三视角占主体。
- 侧面、背面、俯视和仰视用于补结构，不能全部堆在同一服装。
- 同一站姿或原立绘姿势不超过训练集约 15%。
- 手持道具、坐姿、行走、回头、弯腰、抬手、休息等动作要分散。
- 不为追求视角数量保留违反人体逻辑的图。

## 画风与背景

- 至少 3 种兼容画风，但主画风保持 50–60%。
- 避免一张图同时改变脸、发型、服装、画风和年龄。
- 背景需要变化，但不能反复出现同一复杂场景或抢占角色面积。
- 透明／纯色背景只占小部分；全量纯白会削弱场景泛化。

## 评分

每张图按 1–5 分记录：

- 身份相似度
- 脸部质量
- 发型与发饰一致性
- 人体与手部
- 服装正确性
- 构图完整度
- 数据集增量价值

任何身份、人体或构图关键项低于 3 分时，默认进入淘汰区。高分近重复图只保留最有价值的一张。

## Alternate Form

兔形、兽形、幼年或其他不同解剖形态默认单独训练。确需混合时：

- 每种形态至少准备 12–20 张
- 使用独立 form tag
- caption 不混用 `1girl` 与 `animal focus`
- 分别测试人形和 alternate form 的互相污染
