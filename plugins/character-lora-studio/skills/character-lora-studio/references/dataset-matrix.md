# 数据集矩阵

先确定 `concept.type`，再确定数量和覆盖。下面是首版示例范围，不是数量上限或必须执行的配额；用户指定的数量与分阶段计划优先。质量、概念一致性和增量价值优先于凑数。

## Character LoRA

角色人形可在 15–60 张范围内建立首版，通常先用 25–40 张高质量图验证概念。复杂、需要换装的角色可扩展到 40–50 张；少于 25 张时将服装压缩为 2–3 套，40 张以上可使用约 5 套服装。

数量不是门禁本身。先确认每张图中的身份锚点一致，再增加数量和多样性。优先级是：

```text
身份或概念一致性 > 单图质量 > 覆盖完整度 > 数量
```

### 最小视图门禁

在扩展动作、服装和画风前，先确认基础结构覆盖：

| 构图 | 正面 | 侧面 | 背面 | 俯视／仰视 |
|---|---:|---:|---:|---:|
| 头部特写 | 2 | 1 | 1 | 至少覆盖一种 |
| 上半身 | 2 | 1 | 1 | 至少覆盖一种 |
| 全身 | 2 | 1 | 1 | 至少覆盖一种 |

这是生成与审查矩阵，不要求机械地保留每个槽位。人体、身份或构图不合格时宁可留空并补图，也不要为了完成表格把坏图放进训练集。

跨画风泛化阶段可覆盖多种兼容渲染方式，并变化动作、背景和光影；身份基础阶段可以依用户要求限制为少量画风和白底。画风变化不能同时带来脸型、发型、服装结构或身体比例漂移。

### 服装分配

| 类型 | 建议占比 | 目的 |
|---|---:|---|
| 默认服装 | 30–40% | 稳定默认召回 |
| 都市便装 | 15–20% | 解除制服绑定 |
| 半正式／职业装 | 12–18% | 扩展成熟场景 |
| 主题换装 | 10–15% | 保留世界观或原设致意 |
| 居家／轻便装 | 10–15% | 增加材质与身体姿态变化 |

泳装、礼服和极端造型各控制在 2–4 张，优先留到扩展版。不要让单个非默认服装成为第二套隐性制服。

泳装或贴身服装的数量由身体身份特征决定：

- 没有纹身、皮肤花纹、义体或衣下结构特征时，1–2 张通常只用于解除服装遮挡。
- 身体表面存在身份锚点时，增加能清楚显示这些锚点的角度，而不是机械增加裸露度。
- 不需要学习的身体细节不要通过重复泳装图变成隐性概念。

### 镜头分配

| 镜头 | 建议占比 |
|---|---:|
| 头部特写 | 15–20% |
| 上半身 | 30–35% |
| 膝上／大腿构图 | 15–20% |
| 全身 | 25–30% |
| 背面或结构视图 | 5–10% |

每套主要服装至少包含 2 张上半身和 1 张全身。默认服装需要更多正、侧、背结构信息。

## Outfit LoRA

单套复杂衣服 v1 建议 30–50 张。目标是稳定服装并解绑穿着者，因此“不同穿着者”比增加同一人的近重复图更重要。

### 穿着者覆盖

- 至少 5 个明显不同的成年穿着者；8–12 个更稳。
- 改变脸型、发型、发色、瞳色、体型和肤色，同时保持目标服装设计一致。
- 单个穿着者不超过数据集约 25%。
- 不使用目标角色触发词。若只能获得单一角色素材，应将身份泄漏标为高风险，并优先补生成图。

### Outfit 镜头分配

| 镜头 | 建议占比 | 目的 |
|---|---:|---|
| 上半身 | 25–30% | 领口、袖型、胸前结构和配件 |
| 膝上／大腿构图 | 20–25% | 上下装衔接、腰线和层次 |
| 全身 | 30–35% | 整体轮廓、下摆和鞋子 |
| 侧面／背面结构 | 10–15% | 后背、侧缝、尾部和闭合结构 |
| 局部细节 | 5–10% | 材质、纹样、扣件；不得遮蔽整体覆盖 |

正面和四分之三视角占主体，同时至少保留 3–5 张背面或后侧结构。头部特写通常不进入衣服 LoRA，除非服装包含帽子、头巾或领部结构且衣服仍占画面主体。

### Outfit 一致与变化

必须固定：

- 版型和层级关系
- 主辅色
- 主要材质
- 标志性纹样和扣件位置
- 成套配件的纳入范围

必须变化：

- 穿着者身份
- 动作和手臂位置
- 镜头和裁切
- 背景和光照
- 与服装兼容的渲染风格

## Character Outfit LoRA

仅在人物与签名服装必须一体召回时使用。建议 30–50 张，并明确接受以下代价：

- 换装能力弱于独立角色 LoRA
- 服装可能在未写服装提示时泄漏
- 不能可靠地把衣服复用到其他角色

需要同时拥有“可换装角色”和“标志服装”时，优先训练两个独立 LoRA，并在推理端叠加测试。

## Style LoRA

建议 80–200 张起步，至少覆盖多种人物、物体、场景和构图。单一角色或单一背景不得主导，否则触发词会同时绑定内容。

## 视角、动作与画风

- 正面和四分之三视角占主体。
- 侧面、背面、俯视和仰视用于补结构，不能全部集中在同一穿着者或服装。
- 同一站姿或原立绘姿势不超过训练集约 15%。
- 坐姿、行走、回头、弯腰、抬手、休息和交互动作要分散。
- 不为追求矩阵数量保留违反人体逻辑的图。
- 画风配额是项目实验参数；跨画风阶段可使用多种媒材，身份基础阶段可采用少量画风。不要把 50–60% 等经验比例变成门禁。
- Outfit LoRA 以设计一致为第一目标，画风变化应温和，避免同时改变穿着者、服装结构和画风。
- 背景策略按阶段记录。纯白身份包可作为用户选择的受控实验；标注白底不能保证背景解耦，需要在阶段验收中测试非白底场景。

## 评分

每张图按 1–5 分记录：

- 目标概念相似度
- 脸部质量或穿着者解绑价值
- 发型发饰或服装结构一致性
- 人体与手部
- 服装正确性
- 构图完整度
- 数据集增量价值

任何目标概念、人体或构图关键项低于 3 分时默认进入淘汰区。高分近重复图只保留最有价值的一张。

## Alternate Form

兔形、兽形、幼年或其他不同解剖形态默认单独训练。确需混合时：

- 每种形态至少准备 12–20 张
- 使用独立 form 表达
- Caption 不混用 `1girl` 与 `animal focus`
- 分别测试不同形态之间的污染
