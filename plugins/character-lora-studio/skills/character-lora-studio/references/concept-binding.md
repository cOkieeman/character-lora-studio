# 概念绑定决策

## 核心目标

让触发词稳定召回目标概念，同时让不属于目标概念的服装、人物、动作、构图、背景和画风仍可替换。删除 caption 中的词不等于模型看不见图像内容；caption 决定训练时如何分配概念。

## 三类特征

1. **固定概念**：希望主要绑定到触发词的脸、关键发型、核心发饰，或服装版型、配色、纹样和成套配件。
2. **可控概念**：希望提示词能够单独开关的发饰、服装组件、道具或材质。使用稳定 canonical tag 或稳定自然语言表达。
3. **变量**：不应被触发词吸收的穿着者、姿势、表情、镜头、背景、光照和普通换装。逐图如实描述。

每个项目都要在 `角色配置.yaml` 中分别填写身份和服装的 fixed、controllable、variable 与 forbidden drift。用户决定优先于默认建议。

## 触发词设计

- 使用唯一 ASCII 小写触发词，例如 `mirellevane` 或 `mirellenavyoutfit`。
- Character 与 outfit 分开训练时必须使用两个不同触发词。
- Character-only caption 不应把某套非固定服装默认为角色身份。
- Outfit-only caption 不得包含目标角色触发词。
- Character-outfit 组合训练前必须确认用户接受服装泄漏和换装能力下降。
- 触发词单独召回、触发词加完整细节上限、替换测试和无触发词基模回退都要测试。

## 模型族边界

- Anima 使用 Booru canonical tags 管理概念。
- Krea 2 使用英文自然语言 caption 管理概念。
- Anima 中“保留哪些 tag”的规则不能直接当成 Krea 2 的逗号标签模板；应转译为自然语言中保留或省略哪些概念。
- 同一素材的 Anima 与 Krea 2 caption 分开审查、分开导出。

## 正则集

- 正则用于维持通用先验，不是目标概念补图。
- 正则 caption 不得包含任何项目触发词。
- Character 正则排除与目标身份过近的脸、发型、发饰和专属组合。
- Outfit 正则使用穿着普通、多样服装的人物，排除目标服装的完整结构、配色和配件组合。
- 正则的镜头、宽高比和主体类型应接近训练集分布。
- 抓取或生成数量可比目标多约 10–25%，再人工删除人体、构图、色彩或线条混乱的图。
- 保留最终正则图片-caption 对，作为可复用独立资产导出。

## 验证而非照抄

参考截图、平台 UI、caption parser 和模型版本都可能变化。遇到未验证参数时：

1. 记录来源、日期、trainer 版本和目标模型族。
2. 将其标为项目配置而不是插件硬规则。
3. 先做 5–10 step 烟雾测试。
4. 使用固定 seed、基模对照和早中晚 checkpoint 验证。
