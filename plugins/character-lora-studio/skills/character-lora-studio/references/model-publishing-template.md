## 用途与输出范围

本文件用于生成角色 LoRA 的模型介绍，也可拆分为发布编辑器中的常用文本片段。

插件应读取整份参考文件，但发布时只输出 `PUBLIC_TEMPLATE_START` 与 `PUBLIC_TEMPLATE_END` 之间的正文，并完成变量替换及可选段落处理。元数据、填写规则、变量表、版权说明候选和参考来源均不属于公开介绍。

模板使用标准 Markdown：标题分层、关键字段加粗、触发词使用行内代码、完整提示词使用代码块、主要段落使用分隔线。输出适用于 Markdown 文件；粘贴到富文本编辑器后，应检查实际排版是否保留。

## 插件填写规则

1. **按模型与版本填写。** Anima、Krea2 或其他底模版本分别生成介绍，不混用触发词、权重、采样参数和测试结论。
2. **使用可核实的信息。** 触发词保留实际拼写与顺序；参数来自当前版本的测试记录；来源、作者和权利方来自已确认的信息。历史记录与当前记录冲突时，应先核实。
3. **完整提示词可复制。** 保留实际使用的提示词内容，不向触发词中加入 Markdown 符号，不自行增添未经测试的角色特征。
4. **只描述已观察到的改善。** 版本更新说明写明具体变化；未测试的能力不得写成已实现，也不使用“完美还原”“任意换装”等保证式表述。
5. **缺失信息不得编造。** 有价值但尚未确认的信息，列入发布前待确认事项；可选段落缺少资料时整段删除。关键许可信息缺失时，不生成“可直接发布”的最终版，应单独说明缺项。
6. **许可与页面设置一致。** 填写实际许可证名称和链接；商业使用、模型转载、合并、衍生模型及署名要求应与页面设置和适用的上游许可一致。不得自行添加不允许商用、禁止合并或必须署名等条件。
7. **区分权重许可与角色权利。** 模型许可不能代替原作角色、训练素材或其他第三方内容的授权。不得把“非官方”“非商业”或版权声明写成自动获得授权或排除侵权的依据。
8. **按角色来源选择版权说明。** 原创角色、未获官方授权的同人角色、已获授权的角色和来源未明的角色，使用不同文案；不虚构官方授权、合作或背书关系。
9. **共用片段仅保存稳定内容。** 换装建议、示例说明和反馈说明可以复用；触发词、参数、版本更新和具体许可按模型保存，避免编辑共用片段时改变历史版本的事实。
10. **保持自然、具体的中文。** 先介绍模型和当前版本特点，再给出使用方法、测试设置、版本变化和许可范围。保留已确认的不足，不添加模板化宣传。

## 变量与可选段落

变量统一使用 `{{variable_name}}`。它们是填写标记，不是生成提示词语法。发布前应全部替换或随所属可选段落删除。

| 变量                         | 内容与填写要求                           |
| -------------------------- | --------------------------------- |
| `model_name`               | 当前模型的公开名称                         |
| `character_name`           | 角色名称；原创角色也须填写实际名称                 |
| `base_model_family`        | Anima、Krea2 或实际底模系列               |
| `version_name`             | 当前公开版本名称                          |
| `model_description`        | 角色来源及制作方向；不宣称未验证的效果               |
| `version_highlight`        | 本版特点；没有资料时删除这句话                   |
| `trigger_words`            | 已确认的实际触发词；多个触发词应分别展示并说明组合方式       |
| `identity_description`     | 已测试的角色特征描述；可选                     |
| `default_outfit`           | 已测试的默认服装描述；可选                     |
| `tested_base_model`        | 测试使用的底模名称与版本；可附公开链接               |
| `tested_lora_strength`     | 实际测试的 LoRA 强度；需要区分模型与文本编码器强度时明确标注 |
| `tested_sampler_scheduler` | 实测采样器与调度器；可选                      |
| `tested_steps_cfg`         | 实测步数与 CFG；可选                      |
| `tested_resolution`        | 实测图像尺寸；可选                         |
| `positive_prompt`          | 完整、经过测试的正向提示词                     |
| `negative_prompt`          | 对应测试实际使用的负面提示词；不适用或为空时删除这一整项      |
| `previous_version`         | 对照的上一版本；首发版本删除整个更新段落              |
| `version_changes`          | 以列表写明改动及观察到的效果；不得把计划写成结果          |
| `known_limitations`        | 已观察到的偏差或尚未充分测试的场景；无可靠资料时删除整项      |
| `license_name`             | 实际适用的许可证名称；不自动指定 MIT、CC 或其他许可证    |
| `license_url`              | 对应许可证全文的有效公开链接                    |
| `usage_permissions`        | 与许可证及页面设置一致的权限摘要；无额外摘要时删除这一整项     |
| `character_rights_notice`  | 从下方版权候选中选择并完成填写的文案                |

没有额外触发词的模型，应将触发词段落改为“本版本不需要额外触发词”，仅在已经确认这一事实时使用。提示词和参数未实测时，可以生成明确标注“未实测”的草稿，不将其冒充推荐设置。

## 角色版权说明候选

以下候选只用于填入 `character_rights_notice`。选择其中适用的一种，不将所有候选同时发布。候选内的占位符同样需要填写；未经确认的可选来源行应删除。

### 原创角色

* **角色：** {{character_name}}
* **角色设计 / 权利方：** {{original_character_owner}}

本模型以原创角色为主题制作。角色设定及相关内容的使用范围，以权利方实际公布的授权为准；模型权重的许可不自动扩大角色内容的授权范围。

### 非官方同人角色

* **角色：** {{character_name}}
* **出自：** {{source_work}}
* **原作者 / 权利方：** {{confirmed_rights_holder}}

本模型为非官方粉丝制作，与原作官方不存在合作、授权或背书关系。角色及原作相关内容的权利归各自权利人所有。

本模型的发布不意味着原作角色可以自由商用。涉及商业用途时，请分别确认模型许可和原作权利人的授权要求。

### 已获授权的角色

* **角色：** {{character_name}}
* **出自：** {{source_work}}
* **授权方：** {{authorization_provider}}
* **授权范围：** {{confirmed_authorization_scope}}

本模型在上述授权范围内制作和发布。角色及原作相关权利仍归各自权利人所有。本模型的许可不扩大原授权范围，也不自动向使用者转授未包含在原授权中的权利。

只有确认授权实际覆盖模型制作及发布时，才使用此候选；不得仅因获准使用某张素材而推断获得完整角色授权。

### 来源或授权状态待确认

涉及的角色及素材来源、权利方或授权范围尚未确认。本模型的许可不包含对相关第三方内容的授权。

此候选仅用于草稿。发布前应完成来源和授权范围核实，不把“待确认”当作可发布的版权证明。

## 发布前检查

* 公开正文没有残留的 `{{变量}}`、空标题或填写提示。
* 当前版本的触发词、底模、强度、提示词和测试记录相互对应。
* 版本更新可以从对照记录中得到支持；首发版本未保留虚构的上一版本。
* 可选项缺失时整项删除；负面提示词不适用时未保留空代码块。
* 许可证链接有效，权限摘要与许可全文及页面设置一致。
* 角色版权说明适用，来源与权利方没有猜测填写。
* 示例说明与实际附件一致；没有提供生成参数的示例，不宣称附有可复现参数。
* 富文本编辑器中的标题、加粗、行内代码、分隔线和提示词代码块均已检查。
