# Krea 2 训练 Caption：可见事实与概念绑定

用于 Krea 2 LoRA 训练集的英文自然语言打标与审查。它不替代日常生图提示词规则，也不改变 Anima 的 Booru caption profile。根据用户提供的专项人物打标资料整理，并将其身份训练假设改为按项目选择的策略。

## 先决定哪些特征要学到触发词里

结合 [concept-binding.md](concept-binding.md)，在项目配置记录固定、可控和变量特征。没有确认策略时，先审查少量样本，不批量重写既有 caption。

| 训练目标 | 身份与外观 | 服装与内容 |
|---|---|---|
| `character` | 希望整体绑定的身份锚点可以少写；希望独立控制的发型、饰品等使用稳定描述 | 换装、姿势、裁切、背景、光照作为变量写清楚 |
| `outfit` | 描述不同穿着者可见的外貌，避免衣服触发词吸收特定脸或体型 | 固定设计可绑定到 outfit trigger；可控组件及实际穿着状态仍需描述 |
| `character_outfit` | 人物与指定服装按整体绑定 | 描述姿势、镜头、环境和非固定穿着变化 |
| `style` | 如实描述人物外貌、服装、物体与场景，减少重复内容被吸入风格 | 只将预定的画面语言绑定到 style trigger；按项目策略决定媒介和风格词的保留 |
| `cast` | 每个可见成员用独立 token 绑定身份；不添加缺席成员词 | 每人服装、动作和画面位置分别对应，关系清晰；使用逐图成员 manifest 审计 |

“不写脸型、眼睛、痣或纹身”可以是特定人物身份训练的绑定选择，不是 Krea 2 的通用限制，也不能保证相似度提升。发型、体型同样按训练目标和可见程度处理，不要求每图重复。面部表情、视线与身份特征分开判断。

## 逐图描述

- 只写可见事实。不要沿用生成提示词补全遮挡、画外人体、物件、品牌、故事或心理活动。无法辨认的材质、细节和字样不要猜。
- 确认媒介、人物数量、画面裁切与视角。全身、半身、特写应符合实际边界；只有明显时才写广角畸变、透视压缩或景深。局部虚焦要指出位置。
- 用具体身体关系写姿态、表情与视线。区分轻微闭嘴微笑、露齿微笑、张嘴笑；手压在栏杆上与手悬在栏杆上不是同一件事。
- 物体接触优先于意图推断：罐子贴着脸颊就写接触位置，不把它推断成喝饮料。左右侧必须明确是人物自身还是画面方向，避免同一批次混用。
- 环境写关键可见物件、相对位置和空间层次；光照写有证据的来源、方向、软硬及色彩。不要仅凭效果断言具体灯具或相机型号。
- 可辨认的文字逐字引用；难以辨认时用简短的不确定描述。水印、签名、标志等污染应先回到筛图阶段处理，不能靠删掉文字描述修复像素。
- 多人图只区分有必要的人物及其关系；与项目筛选规则冲突的污染图先标记复审。
- Cast 图明确写出所有可见目标成员及位置，不用普通群像规则省略成员触发词。
  示例与单人/配对 manifest 见 [Cast 流程](../../krea2-character-dataset-prep/references/cast-workflow.md)。

## 服装：物件结构与穿着状态分别写

按从外到内的层次描述与本项目相关且可见的细节，避免将下面的维度变成每张图都必须填写的表格。

1. **衣服是什么**：类型、颜色、图案、领口、肩带、衣长、轮廓、开口与结构配件。材质不明确时写可见质感，不编造纤维名称。
2. **如何贴合**：贴身、合体、宽松、高腰等。需要同时说明贴合与材质时，可写 `a fitted ribbed-knit sweater`，避免材质词替代版型信息。
3. **透光与覆盖**：透明度或露肤确实可见且影响训练目标时，中性说明覆盖边界。不要推断衣物下面的身体细节，不强制填写身体部位模板。
4. **现在怎么穿**：扣合或敞开、袖子卷起、肩带滑落、上衣塞进裙腰等。区分衣服本身设计与临时位置。
5. **移位仍保留原物件名**：外套滑到肘部仍是外套，不能因位置变化改叫其他衣物。
6. **左右不对称分侧描述**：一侧正常穿袖、另一侧滑落时，分别写清，不能概括成两边都露肩。
7. **连体结构只命名一次**：连在同一件衣服上的带子、搭扣和配件写成它的组成部分，避免拆成几件独立衣物。
8. **套装与层叠关系**：只有匹配关系可见时才称套装，鞋袜只在可见范围写。明确的服装类型词可保留；不要为抵消刻板联想而凭空列出一长串不存在的配件。

时代、类型或亚文化词不是绝对禁用项。具体结构优先；标签准确且与项目策略一致时可以简短保留。删除 `masterpiece`、`best quality`、`8k`、漂亮等质量评价与空泛赞美。

## 输出与长度

- 每图一个同名 UTF-8 `.txt`，正文为连贯英文段落，不含分析、标题、负面提示词或模型参数。
- 常用顺序是主体与媒介 → 裁切视角 → 姿态表情 → 服装与接触 → 环境光照；按图中重点调整。
- 约 80–150 个英文词可作为复杂人物图的参考预算，不是下限。简单图更短；复杂图保留重点，不为凑字补写细节。
- 词数不等于 tokenizer token 数。核对实际 trainer 与文本编码器版本的截断规则；现有 512 token 说明只对应已记录的 AnimaLoraStudio 0.23.1 文档，版本变化后重查。
- 若导出器负责追加触发词，caption 草稿不要重复插入。记录唯一的触发词组装位置，导出后检查最终 `.txt` 中的出现次数与拼写。
- 训练用自然语言不做 tag shuffle 或 tag dropout；不将 Anima 的 `keep_tokens` 方案套到 Krea 2。

## 示例：角色身份，服装作为变量

```text
exampleperson is shown from the waist up in a three-quarter view beside a wooden window. She looks toward the camera with a slight closed-mouth smile. She wears a fitted cream ribbed-knit sweater beneath an open navy coat, with the coat sleeves pushed up to her elbows. Her right hand rests on the windowsill. Soft daylight enters from the left, while shelves and a pale wall remain visible in the background.
```

示例仅演示组织方式，不能作为整批通用 caption。身份锚点是否省略应服从项目配置。

## 导出前复审

对照原图核查裁切、人物数量、左右、视线、手与物体接触、衣服件数、层叠及移位、光源证据。检查固定/可控/变量策略在全批一致，触发词不重复，内容不越过实际可见范围。保留修改前快照、逐图复审状态与修改统计；改动 caption 后使受影响的文本缓存和冻结导出失效。这里的规则本身不授权改写现有数据集或启动训练。
